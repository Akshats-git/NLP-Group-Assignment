# NLP-Group-Assignment

Assignment brief: [`Group Assignment 1.pdf`](Group%20Assignment%201.pdf).

## Layout

- [`Question-1/`](Question-1/) - Word segmentation and POS tagging on unspaced text, English and Spanish. Report: [REPORT_Q1.md](Question-1/REPORT_Q1.md).
- [`Question-2/`](Question-2/) - Arc-standard transition-based dependency parser. Report: [report.md](Question-2/report.md).
- [`Question-3/`](Question-3/) - Spelling corrector for non-word and real-word errors, with the Speed Demon benchmark and a terminal app.
- [`Question-4/`](Question-4/) - Live Streamlit editor that runs the Q1 decoder, the Q3 corrector and a PCFG parser over one text stream. Report: [REPORT_Q4.md](Question-4/REPORT_Q4.md).

Each folder has its own README with setup and usage instructions. Question 4 reuses the
trained models from Questions 1 and 3 rather than retraining them, so set those two up
first if you want to run it.
